DECISION GUIDE

先解决业务，再增加分布式成本

四套工程共享 UI 与接口约定，迁移时可以保留用户心智和前端资产。单体并不是临时 Demo，而是具备明确模块边界的正式交付形态。

  1. 01
    默认选模块化单体人员较少、领域仍在快速变化时，优先 Java 或 Go 单体。
  2. 02
    按真实瓶颈拆分出现独立扩缩容、故障隔离或团队自治需求后，再采用 Cloud 版本。
  3. 03
    保持数据库基线一致四套工程默认 MySQL 8.4，降低本地、测试与部署环境差异。
