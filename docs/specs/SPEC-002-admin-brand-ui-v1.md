# SPEC-002 Nimbus 运营后台品牌体验 v1

## 状态

`verified`

## 目标

- 移除上游脚手架遗留的兔子头像、图片 Logo、加载动画和浏览器图标。
- 建立适合通用微服务脚手架的中性企业品牌、品牌文案与登录体验。
- 保持若依上游业务页面、表格、卡片、表单、弹层、导航和标签页的原始实现。
- 与暮色平台共享品牌资源规范，同时保留 Nimbus 独立的 N 品牌标识。

## 范围

- 登录与二维码品牌标识、默认用户头像、锁屏与消息头像。
- 首屏加载状态、全局异步加载状态与进度反馈。
- Nimbus 登录页的品牌文案与视觉。

## 非目标

- 不修改业务页面中的表格、卡片、表单、按钮、弹窗和抽屉样式。
- 不修改顶部栏、侧栏、标签页和内容容器的上游布局或交互。

## 验收标准

- 源码不再引用 `avatar.gif`、`logo.png`、`logo.gif` 或旧 `favicon.ico`。
- 除品牌资源引用外，上述非目标组件与上游源码保持一致。
- Nimbus 通过类型检查和生产构建。
- 品牌资源与暮色平台明确区分，公共组件视觉规范保持一致。
