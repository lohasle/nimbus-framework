# 开发标准

## DDD

- System、Infra、Member、Pay、Application、IM、App 是独立限界上下文。
- `nimbus-module-app` 是集成应用，只能调用其他模块公开 API，其他模块禁止依赖它。
- 跨模块调用优先依赖 `api` 契约，禁止直接访问其他模块 Mapper。

## SDD

- 跨模块、接口、数据结构、权限或发布方式变化必须先更新编号 Spec。
- Spec 必须包含目标、非目标、接口、数据、错误、验收和测试计划。

## TDD

- 先列测试场景，再实现状态机、转换器、权限与核心业务规则。
- 修复缺陷必须补回归测试；模板模块至少需要上下文加载测试。

## Java 与数据库

- JDK 25、Spring Boot 4.x；包名统一为 `com.nimbus`。
- MySQL 8.4 为默认生产数据库基线；PostgreSQL 适配同步维护，数据库特有 SQL 分目录提交。
- 表、索引、唯一约束和迁移必须可重复部署，生产禁止自动改表。

## API 与安全

- 管理端前缀 `/admin-api`，APP 前缀 `/app-api`，内部契约单独标识。
- 所有接口提供 OpenAPI 文档；日志禁止输出密码、Token 和支付密钥。
- 密钥只允许通过环境变量或密钥管理服务注入。
